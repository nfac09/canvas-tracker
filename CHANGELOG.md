## [1.0.0] - 2026-03-26

Initial release of Canvas Tracker.

- Dashboard with smart grouping: Overdue, Today, This Week, Upcoming
- Recurring assignment patterns that auto-generate weekly assignments
- Canvas iCal import with automatic deduplication (safe to re-import)
- Grades page with course-level summaries and progress bars
- Dark mode with smooth theme toggle
- macOS desktop app with native window controls and traffic lights
- Automatic update detection with in-app download progress
- What's New modal shown once per version after updating
- GitHub Actions CI/CD for automated release builds
